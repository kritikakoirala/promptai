# 🤖 Prompt AI (Learning Project)

[![Live Demo](https://img.shields.io/badge/Live-Demo-blue?style=flat-square)](https://promptai-theta.vercel.app)
[![Built with](https://img.shields.io/badge/Built%20with-Next.js%20%26%20MongoDB-black?style=flat-square&logo=next.js)](https://nextjs.org/)
[![License](https://img.shields.io/badge/license-MIT-green?style=flat-square)](LICENSE)

**Prompt AI** is a demo project built for learning purposes. It is a web application built with **Next.js**, **MongoDB**, and **NextAuth.js** for authentication, styled with **Tailwind CSS**. The app demonstrates basic user authentication, data management with MongoDB, and modern React features.

> ⚠️ This project is for educational use only and not intended for production deployment.
> You can check out the **live demo** of this project here: [https://promptai-theta.vercel.app](https://promptai-theta.vercel.app)


---

## 🧱 Tech Stack

- **Next.js** – React framework for server-rendered apps  
- **MongoDB & Mongoose** – NoSQL database and ODM for data management  
- **NextAuth.js** – Authentication solution for Next.js  
- **bcrypt** – Password hashing for security  
- **Tailwind CSS** – Utility-first CSS framework for styling
